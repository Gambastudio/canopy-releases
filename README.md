# Canopy Releases

Signed builds and the update feed for **Canopy**, a fast storage analyzer for macOS.

- Downloads: see [Releases](https://github.com/Gambastudio/canopy-releases/releases)
- Update feed (Sparkle): `https://gambastudio.github.io/canopy-releases/appcast.xml`

This repository contains release artifacts only; the source code is not public.
